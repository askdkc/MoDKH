# Web検索と外部取得

`web_search` と `fetch_url` は、ワークスペースの外にある情報を取ってくるためのツールです。どちらも**外部への通信**なので、既定の承認ポリシー（`workspace`）では毎回確認します。

## 承認

| ポリシー | 動作 |
|---|---|
| `all` | 確認せずに実行する（`(自動承認: command — …)` と記録に残る） |
| `workspace`（既定） | 通信のたびに確認する |
| `none` | 通信のたびに確認する |

- 承認の表示には、送信先ホスト・URL・検索語・上限が入ります。**何が外部へ送られるかを見てから**決めてください。
- `fetch_url` は**転送（リダイレクト）のたびに**承認を求めます。転送先は、人間が承認したURLとは別の場所になり得るためです。拒否すれば、その先へは進みません。
- 承認と通信の間に Stop や中断が入った場合は、結果不明として返します。再送するかどうかは呼び出し側が判断してください。

## キー

`web_search` は Brave Search API を使います。

```sh
export BRAVE_SEARCH_API_KEY="..."   # 環境変数（優先）
```

または MODKH に保存します（`~/.config/modkh/keys.json`、0600。`MODKH_HOME` 指定時はその配下）。

```text
/connect brave-search
```

`fetch_url` はキー不要です。

## 取得の上限

| 項目 | 既定 | 変更 |
|---|---|---|
| 受信バイト数 | 512 KiB（最大 2 MiB） | `fetch_url` の `maxBytes` |
| 制限時間 | 30 秒（最大 120 秒） | `fetch_url` の `timeoutMs` |
| 表示する本文 | 32 KiB 文字 | 固定 |
| 検索件数 | 5 件（最大 10 件） | `web_search` の `count` |

打ち切った場合は、結果の中に「打ち切った」と残します。黙って切り詰めることはありません。

## 返るもの

- `fetch_url`: 状態コード、`content-type`、受信バイト数、転送回数、最終URL、本文。HTML はタグを落として本文だけにします（`script` / `style` は除去）。
- `web_search`: 検索語、件数、タイトル、URL、要約。本文は返しません。続きは `fetch_url` で取得します。
- テキストでない応答（バイナリ）は、本文を表示せずにその旨だけ返します。

## 制限

- **結果の真偽は保証しません。** 取得した内容を事実として扱わず、必要な場合は出典を確認してください。
- 検索は Brave Search のみに対応しています。他の検索APIを使う場合は `createWebSearchTool({ searchEndpoint })` で差し替えます。
- `http` / `https` 以外のスキームと、URLに資格情報を埋めた指定は拒否します。
- プライベートアドレス（`127.0.0.1` や社内ホスト）への取得は**塞いでいません**。承認画面でホストを確認してください。
- どちらも `readOnly: true` として扱うため、失敗しても「副作用なし」と記録されます。ワークスペースのファイルは変更しません。
- サブエージェントにも同じツールが渡ります。承認の表示には子のセッションIDが付き、人間の承認は変わりません。
